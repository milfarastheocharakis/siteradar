    Google key for the website check

    The website check uses Google's free PageSpeed service, which needs your own key. It costs nothing and needs no card. The key is saved only in this browser.

    1. Open the PageSpeed Insights API page, sign in with Google, pick or create a project, and press Enable.
    2. Open Credentials, press Create credentials, then API key.
    3. Optional: edit the key and, under API restrictions, allow only the PageSpeed Insights API.
    4. Copy the key and paste it below.
